# /final 目次レイアウト比較

この試作は目次だけの比較用です。`app/final/page.tsx`、`lib/book-layout.ts`、`app/globals.css`、注文PDF・本文・表紙・決済は変更・使用しません。

## 正式採用

正式採用は比較PDF `four-works-A-B-C-A6.pdf` の1ページ目にあるA版（現行の縦書き目次）です。D40/D45の下方配置案は採用を取り消し、通常画面・注文PDFには反映しません。A版はすでに `/final` の `TableOfContents` として実装されているため、採用に伴う本番レイアウトの変更はありません。

比較PDFの4作品版はレイアウト見本用の固定ページ数を使うため、そこに表示されるページ番号は実作品の確定値ではありません。通常の `/final` は各作品の本文を実際に組版したページ数から目次ページ数と開始ページを計算します。目次が複数ページになる場合も、確定した目次ページ数を使って開始ページを再計算します。

通常の注文用PDFと開発用検証PDFは、どちらも `renderLocalFinalBodyPdf` から固定の `/final` を描画するため、同じA版目次を使います。B/C/D40/D45は比較用の生成物としてのみ残します。

## 実行

```powershell
npm run compare:final-toc
```

生成物はGit管理対象外の `tmp/final-toc-comparison/` に保存します。

- `four-works-A-B-C-A6.pdf`：従来A、横組みB、縦書きCの比較
- `four-works-A-B-C.png`：A/B/Cの1ページ目の並列画像
- `four-works-C-D40-D45-A6.pdf`：現行C、タイトル開始位置40%のD40、45%のD45の比較
- `four-works-C-D40-D45.png`：C/D40/D45の1ページ目の並列画像
- `pagination-stress-A-B-C-A6.pdf`：架空18作品によるA/B/C比較
- `pagination-stress-C-D40-D45-A6.pdf`：架空18作品によるC/D40/D45比較
- `measurements.json`：順序、サンプル開始ページ、目次ページ数、A6寸法、タイトル位置、余白、折り返し、重なりの計測結果

## CとDの配置

Cの作品名・著者列はページ上端から39mmの位置で始まります。D40とD45では、作品名と著者名の列を一律に下げ、上端をそれぞれページ高さの40%（59.2mm）、45%（66.6mm）に揃えます。作品ごとの個別中央揃えはしません。目次見出しは上部に残し、ページ番号は現在のCと同じページ上端から108mmの専用欄に置きます。

Dでは下端の21mm余白を保つため、開始位置が下がるほど一列あたりの文字数を減らします。長い作品名・著者名は必要な縦列へ折り返し、その分の欄幅を使って右から左へ並べます。幅に収まらない場合は追加ページへ送り、ページ数が確定するまで既存の `calculateWorkStartPages` で作品開始ページを再計算します。開始位置、番号の固定、列・番号の重なり、本文領域からのはみ出しはChromiumの印刷メディア上で検査します。

## 比較条件と制約

Aは `/final` の現行目次CSS、Bは前回の横書き案、Cは前回の縦書き案です。D40/D45は比較専用で、通常の目次へ適用していません。

4作品版には現在の短編集と同じ作品名・著者名を使いますが、本文データやブラウザー状態は読み込まず、ページ番号用のサンプル本文ページ数 `[20, 1, 19, 14]` を使用します。したがって表示された開始ページは実作品の確定値ではありません。ストレス版は長い架空の作品名・著者名を含む18作品です。実際の作品ページ数・開始ページと最終デザインは、実作品で確認してから決定してください。
