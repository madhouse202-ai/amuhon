# 権利台帳 初期候補データ（2026-11-20）

この文書と隣接するSQLは登録候補の準備資料です。DBには登録していません。**3作品ともB（要確認）であり、販売・注文可能の承認ではありません。**

## 版の取得と識別

- 公式カタログ：<https://www.aozora.gr.jp/index_pages/list_person_all_extended_utf8.zip>
- カタログを取得した日：2026-11-20
- 版解決：注文APIと同じ `lib/aozora-edition.ts` の `resolveAozoraWorkEditions()` を使用。作品ID、図書カード、テキスト配布URL、XHTML URL、関係者、`sourceMetadata` を公式CSVから解決し、XHTMLの応答ボディそのもの（デコード前の実バイト列）のSHA-256を計算した。
- `text_url` はカタログ記載の配布物（ZIPを含む）。注文時の版ハッシュ対象は `xhtml_url` のXHTML応答バイト列。
- 作品IDはカタログのゼロ埋め値を保つ。URL内の作品番号と作家フォルダ番号は異なる体系。
- URL・ハッシュは取得時点の識別値。登録前に同じ関数で再取得し、一致しなければこのSQLを使用しない。

## 権利確認の根拠と限界

1. 青空文庫の「著作権の消滅した作家名一覧」は3名を掲載し、それぞれの没年月日を示す。ただし青空文庫自身が「一部」「目安」「網羅的・完全ではない」と明記している。作品単位の最終承認根拠として単独使用しない。
2. 公式拡張カタログは各行の `作品著作権フラグ` と `人物著作権フラグ` をともに `なし` とする。作品カードでも翻訳者・翻案者は確認されず、 resolver が返す関係者は著者1名。ただしフラグはAmuhonの個別法務審査の代替ではない。
3. 文化庁の説明では個人著作者の保護期間は原則死後70年。2018-12-30施行の延長により原則として1968年以降に亡くなった著作者が延長対象となった。青空文庫記載の3名の没年（1916、1927、1933）はその境界より前で、今回の延長による再延長の対象ではないと読める。ただし法域・公表形態・旧法・戦時加算等の個別事情を含めた法律意見ではない。
4. 青空文庫の取扱規準は、著作権が切れた作品のファイルについて有償・無償を問わず複製・再配布等を認め、青空文庫側への対価・了解を不要としている。一方で由来情報を削除しないことを希望し、著作権が切れていない作品は私的使用の範囲を超えた複製等に許諾が必要、翻訳作品では翻訳者の権利も別途生じると説明する。
5. 文化庁は保護期間満了後も著作者人格権に関する死後の人格的利益（著作権法60条）や、二次的著作物・素材ごとの権利確認が必要になり得ると説明している。

そのため、登録案は権利台帳の `status='B'`、`rights_reviews_complete=false`、各権利者も `status='B'` に固定した。既存の注文API・決済・生成経路はAと全権利者のAを要求するため、これらのB行では販売へ進めない。

## staging登録前に人が確認する項目

- 最新の公式カタログ／XHTMLの内容・URL・SHA-256が草案と一致すること。ハッシュが変わった場合は旧草案を使わない。
- 作品本文・XHTMLの全体に第三者の文章、図版、追加解説、編集上の独自表現等が混入していないこと、底本と表記変更履歴が適切であること。
- 各作品が国内の単独オリジナル作品であるという判断、保護期間・経過措置・外国著作物等の該当有無、死後の人格的利益に配慮した本文編集・出典表示。
- Aozora本文ファイルの利用条件に沿った出典・入力・校正等の表示方法。青空文庫の関与・承認を示す表示にしない。
- 登録SQLの `NULL::timestamptz` と `NULL::text` を、実際に確認した日時・担当者へ置換すること。両列はDBでNOT NULLのため、そのままでは挿入に失敗する。担当者名を推測で埋めない。
- 人による個別レビュー完了までは、親レコードと全ての権利者をBのままにすること。A判定にする場合は別途、全根拠・条件を記録した上で明示的な人間の承認と台帳更新レビューを行うこと。
- Aozoraカードの初出・校正版などの空欄は空欄のまま扱う。追加確認で判明した場合だけ記録する。
