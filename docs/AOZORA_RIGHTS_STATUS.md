# 青空文庫の権利状態判定と本文版管理

## A/B/Cの意味

- **A**: サーバーが取得した青空文庫公式カタログで、作品・人物の著作権フラグがすべて「なし」であり、初期運用範囲（特定済みの単独著者）を満たす状態。運用上の判定であり、法的保証ではない。
- **B**: フラグの欠落・不明・矛盾、関係者の不足、翻訳・翻案・共同著作、情報不整合などがあり、通常販売へ進めない状態。
- **C**: 作品または関係者のフラグに「あり」が含まれる状態。別の許諾管理を導入するまでは販売対象外。

分類ロジックは `lib/aozora-commercial-rights.ts` にあり、注文APIは作品IDだけを受け取ってサーバー側で公式カタログを再取得する。ブラウザー申告の分類・版URL・SHA-256は受け付けない。青空文庫は公式の著作権区分をJapan SearchのPDM等に対応づけていますが、作品ファイルの誤りの可能性や、翻訳者等の別個の権利も明記しています。個別の法的判断が必要な例外はBへ回し、Aを無条件の保証と扱いません。

参照：

- [青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)
- [青空文庫収録ファイルへの記載事項](https://www.aozora.gr.jp/guide/kisai.html)
- [青空文庫の著作権フラグとJapan Search連携の説明](https://www.aozora.gr.jp/soramoyou/soramoyou2023.html)

## 著作権状態と本文版

著作権状態は公式作品・人物フラグから判定し、XHTMLのSHA-256は印刷する本文版の識別だけに使う。公式カタログ全体のハッシュや取得日時が変わっただけでは当該作品の権利状態を変えない。一方、注文作成時の版とCheckout時またはPDFワーカーが取得した版のSHA-256が違う場合は、価格・注文内容の前提を維持できないため fail-closed で処理を止める。

新しい注文はAだけに限定する。Checkoutは保存済みスナップショットの作品IDをサーバーで再解決し、選択作品のフラグ・関係者・書誌情報・XHTML URL・XHTML実バイトSHA-256を再照合する。PDFワーカーも固定ホストの公式XHTMLを再取得し、A判定と版SHAを照合してから組版・Storage保存へ進む。新しい解決処理で公式情報を取得できない場合も処理を止める。

旧スナップショットは既存の edition-bound 権利台帳で引き続き検証する。過去の注文、支払い状態、ファイル、台帳行をこの変更で更新・削除しない。

## 手動販売停止

追加マイグレーション `20261121000100_aozora_official_rights_status.sql` は追記型の停止・解除イベントを作る。最後のイベントが `stop` なら、注文時の権利RPC、Checkout前チェック、PDFジョブclaim/finalize、管理者の入稿可否チェックを拒否する。Claim前に停止中ならジョブはキューに残り、停止解除後の次回claimで処理できる。Claim後に停止された場合は、最終確定RPCが拒否し、非公開の試行用Storageオブジェクトは注文に紐付かない。既存の有料注文を削除・返金・再決済せず、未入稿の処理を止めるだけ。

マイグレーション適用後、運営者はSupabase SQL Editor（DB所有者権限）で実際の理由・担当者を指定して記録する。以下は**テンプレートで、未実行**。

```sql
select public.set_amuhon_work_rights_manual_stop_v1(
  '<青空文庫作品ID>',
  'stop',
  '<具体的な停止理由>',
  '<実際に操作する担当者名>'
);
```

解除も履歴を残すため、同じ関数で `stop` を削除するのではなく、`resume` イベントを追加する。

```sql
select public.set_amuhon_work_rights_manual_stop_v1(
  '<青空文庫作品ID>',
  'resume',
  '<解除を判断した理由>',
  '<実際に操作する担当者名>'
);
```

イベント表はRLS有効、通常ロールからの直接読み書き不可、UPDATE/DELETE禁止。現行マイグレーションはこのリポジトリに作成しただけで、stagingを含むDBには適用していない。

## 旧一括審査ツール

既存のバッチ審査・SQL生成スクリプトと旧台帳は、過去の記録・明示的な例外調査との互換のため残す。新しい注文A判定の必須経路ではない。旧登録SQL生成器はユーザー操作による別用途であり、この作業では実行しない。
